Calculator Application

This learning exercise showcases practical application of the following JavaScript concepts:

  • How to create named functions
  • How to retrieve and parse input values from HTML elements
  • How to store values in variables
  • How to use conditional if statements to output different results
  • How to use conditional switch statements to use case strings to carry out operations based on the case
  • How to assign the result of operations to a variable and output the result as HTML
