# film-review-application

A simple application for displaying movie information and simple metrics using **React** and **Vite** as part of my journey learning React and modern front end development.

The app allows users to view a selection of movie information, obtained from an API, along with some simple filtering and sorting options.

## Built With

- React
- JavaScript
- Vite
- Tailwind CSS (v4)

## Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser to use the app.

## Learning Goals

- Using async functions, fetch and await to process data from an open API ()
- Using sort and filter to render different outputs depending on user input

- Handling user interactions and updating state accordingly
- Applying conditional rendering based on state
- Using Tailwind CSS for styling components
