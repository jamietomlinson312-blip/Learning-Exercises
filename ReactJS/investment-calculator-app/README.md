# Investment Calculator

A simple investment calculator built with **React** and **Vite** as part of my journey learning React and modern front end development.

The app allows users to calculate how regular investments and compound growth can affect the value of an investment over time.

## Built With

- React
- JavaScript
- Vite
- Tailwind CSS (v4)

## Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser to use the app.

## Learning Goals

The goal of this project is to practise building functional React components, working with user input and managing application state.
